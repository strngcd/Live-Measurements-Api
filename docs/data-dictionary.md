# Data dictionary

Generated by `python -m benchmark dictionary` from `benchmark/schema.py`, `benchmark/definitions.json` (definitions version 2) and `benchmark/garments.json` (garments version 1); do not edit by hand.

All lengths are in centimetres. Codes are pseudonymous: never put names, phone numbers or emails in any table.

## people.csv

| Column | Required | Format | Description |
|---|---|---|---|
| `person_id` | yes | code | Pseudonymous participant code, e.g. P0001. Never a name, phone number or email. |
| `consent_status` | yes | one of: `granted`, `withdrawn` | Current consent. People who withdraw are excluded and their photos must be deleted. |
| `consent_version` | yes | text | Version of the consent form the person signed. |
| `consent_date` | yes | date, YYYY-MM-DD | Date consent was given. |
| `consent_scope` | yes | one of: `evaluation`, `evaluation_and_training` | What the person's data may be used for. |
| `delete_by` | yes | date, YYYY-MM-DD | Date by which the person's photos must be deleted. |
| `split` | no | one of: `train`, `calibration`, `test` | Assigned once by `python -m benchmark splits`; never edit it by hand. |
| `sex` | no | one of: `female`, `male`, `other`, `undisclosed` | Optional; used only to compare errors between groups. |
| `age_band` | no | one of: `18-24`, `25-34`, `35-44`, `45-54`, `55-64`, `65+` | Optional; used only to compare errors between groups. Adults only. |
| `skin_tone` | no | whole number, 1 to 10 | Optional Monk Skin Tone scale value, 1 (lightest) to 10 (darkest), to check errors across skin tones. |
| `notes` | no | text | Free text. No names or other identifying details. |

## Measurements by garment

Measurements each garment needs. `merchant` entries come from the merchants' requirements forms (2026-10-20 and 2026-10-21); `standard` entries are usual in tailoring for the same cut and wait for a merchant to confirm them and give a tolerance. Tolerance is the largest error that still sews into a good fit without alterations; ease is what the tailor adds to the body measurement.

## API outputs compared with tape measurements

| API output | Compared with | Definitions | Note |
|---|---|---|---|
| `shoulder_width` | shoulder_width | differ | The API measures a straight line between shoulder-joint landmarks (x 1.1); the tape follows the back between the shoulder points. |
| `arm_length` | arm_length | differ | The API measures only the vertical drop from the shoulder to the wrist landmark. |
| `trouser_length` | trouser_waist_to_ankle_length | differ | The API measures from the hip-joint landmark to the ankle landmark; the tape starts higher, at the top of the hip bone, and follows the hip, so a systematic gap is expected. |
| `chest_circumference` | chest_circumference | same |  |
| `waist` | waist_circumference | same |  |
| `hip` | hip_circumference | same |  |
| `neck` | neck_base_circumference | same |  |
| `thigh_circumference` | thigh_circumference | same |  |
